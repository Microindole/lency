# Sema 模块

本目录实现自举编译器当前所需的名称解析、作用域和强静态类型约束。

| 路径 | 职责 |
|---|---|
| `symbol.lcy` | 符号数据结构 |
| `scope.lcy` | 分层符号表 |
| `resolver.lcy`、`resolver/` | 声明预载、表达式和语句解析、类型一致性检查 |

## 边界

- 可解析不代表语义合法；错误必须在这里明确报告。
- `Result`、`Ok`、`Err` 不是预置名称，用户同名声明只按普通 enum 处理。
- `TYPE_UNKNOWN` 只能表示尚无法确定的信息，不能长期掩盖已知不一致。
- sema 不负责生成 LIR 或决定 LLVM ABI。
