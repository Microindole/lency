# Rust 母体固化验收

这些用例由 xtask 的 stage0-check 构建并实际执行，同时覆盖普通与优化生成代码。验收检查退出码、输出、错误来源和手动分配余额；运行超时直接失败，不将仅编译成功视为通过。

| 文件 | 范围 |
|---|---|
| control.lcy | 循环、跳转、递归、相互递归、作用域与求值顺序 |
| values.lcy | 数组、集合、组合、方法、枚举、泛型与可空值 |
| library.lcy | 字符串与路径函数的返回归属和临时对象释放 |
| files.lcy | 文件输入输出、参数与分配归属 |
| failure.lcy | 运行时错误、方法调用栈和失败即终止 |

语义负例由验收入口生成到 target/stage0_check，不修改源码。生成程序和日志也位于该目录。
