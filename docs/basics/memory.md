# 手动内存管理

本页描述 Rust 母体 AST 编译路径。当前不提供自动 GC、引用计数或作用域退出自动释放。Lency 自举编译器的 LIR 路径尚未提供同等统一释放契约。

## 分配与归属

结构体与枚举构造、动态集合、新生成的字符串，以及标量或固定数组转换为可空值时，会产生需要释放的堆对象。字符串字面量和普通固定数组本身不需要释放。调用者应保留分配结果，避免无法释放的匿名临时对象。

赋值和传参共享现有堆对象，不自动深拷贝、不自动转移归属。接口需要明确参数是借用还是接收归属，返回值是借用还是新分配结果。借用者不释放对象；拥有者在所有借用结束后释放一次。编译器当前不检查这一约定。

```lency
struct Item {
    int value
}

Item make_item(int value) {
    return Item { value: value }
}

int main() {
    var item = make_item(7)
    int result = item.value
    free(item)
    return result - 7
}
```

释放后，原变量及其所有别名都不可再访问对象。释放调用不会自动清空变量；给一个别名赋空也不会使其他别名安全。覆盖或丢弃最后一个拥有引用前，需要先释放原对象。

## 浅层释放

释放只销毁目标对象自身以及容器实现拥有的内部缓冲区，不递归释放字段或元素指向的独立对象。共享和循环引用需要程序安排释放顺序，并保证释放过程中不再访问已销毁对象。

```lency
int main() {
    var text = "hello" + " world"
    var parts = split(text, " ")
    free(parts[0])
    free(parts[1])
    free(parts)
    free(text)
    return 0
}
```

拆分产生的字符串元素与容器分别拥有独立分配。插入已有对象不会自动复制对象；多个槽保存同一个引用时，不能按槽重复释放。

## 可空值

可空引用直接保存对象地址；可空标量和固定数组使用独立堆上值单元。已有可空值的赋值、参数传递和返回不会复制其值单元。非空检查不改变释放目标，释放后可将原变量置空。

```lency
int main() {
    int? value = 7
    int result = value ?? 0
    free(value)
    value = null
    free(value)
    return result - 7
}
```

空引用释放无操作。普通整数、浮点数、布尔值、函数和非可空固定数组不能传给统一释放入口。静态字符串虽然具有字符串类型，但不属于动态分配，释放时会触发 panic。

## 外部资源与检查边界

母体内置入口的归属契约如下。借用只在调用期间有效，不会因传参而由被调用者释放。

| 入口 | 参数归属 | 返回值与释放责任 |
|---|---|---|
| print、len、write_file、file_exists、is_dir、parse_int、parse_float | 借用 | 无新分配结果 |
| trim、substr、join、format、int_to_string、float_to_string、char_to_string、arg_at | 借用 | 成功产生的新字符串由调用者释放，即使内容为空或与输入相同 |
| read_file | 借用路径 | 新字符串由调用者释放 |
| split | 借用输入与分隔符 | 新容器及每个子串分别由调用者释放 |
| 结构体、枚举构造与非空集合字面量 | 字段或元素中的已有引用仅共享，不复制对象 | 新对象由调用者释放，独立子对象归属不自动改变 |
| 集合读取与弹出 | 借用容器 | 引用元素仍指向原对象；弹出移除槽位，不自动销毁元素 |
| 集合追加与覆盖 | 借用容器，保存传入引用 | 不接管元素归属；覆盖不会释放旧元素引用的对象 |

空集合字面量也会分配容器。标量转换为可空类型会分配值单元，包括参数和返回值边界；这种转换不自动建立归属转移协议。需要释放的转换结果应由接口明确接管，或先保存为有名字的可空变量再传入，避免产生无法回收的匿名值单元。

标准字符串模块中返回字符串的包装，以及标准 I/O 模块中的路径查询与拼接，均返回独立字符串，包括空结果和无需修改输入的分支。输入保持借用，调用者释放返回值。文件行读取返回的容器与各行分别释放；写入及追加函数只借用输入并在内部释放自己的临时字符串。

这些约定不自动推广到任意第三方包装。标准库回归通过分配余额检查其内部临时对象，不将进程退出时由操作系统回收内存视为已正确释放。

旧整数句柄形式的整数键和字符串键 HashMap 分别使用专用入口；这两个入口不会释放值槽引用的独立对象。

```text
hashmap_int_free(map)
hashmap_string_free(map)
```

runtime 文件句柄使用对应的关闭接口，不对任意外部资源约定通用释放。外部函数获得的原始地址，必须使用其接口约定的分配器和释放函数。

运行时记录分配器，保证已登记对象使用匹配的释放方式；未登记地址和地址尚未复用时的重复释放触发 panic。该机制不是所有权系统，不能检测全部释放后使用，不能可靠识别地址复用后的旧别名，也不会自动修复或回收泄漏。
