# 基础语法

## 阅读范围

Lency 使用 C 系的类型在前声明和花括号块结构。语言方向以[设计原则](../design.md)为准；编译器当前能力以[自举状态](../development/status.md)为准。

本目录中标为 Lency 的完整程序示例面向 Rust 母体。标为自举前端的示例仅用于自举开发；两套实现的差异会单独说明，不能将其中一套的接受行为当成新的语言规则。

## 文件与入口

源码扩展名为 .lcy。普通程序在文件顶层声明函数和类型，将可执行语句放进入口函数。

```lency
int main() {
    print("hello\n")
    return 0
}
```

入口返回整数，零表示程序成功结束。函数签名中返回类型放在函数名前，参数也采用类型在前的形式。

自举前端还接受顶层可执行语句，并为其生成入口。这是当前前端接受范围的差异，普通程序示例不依赖这种形式。

## 块与作用域

花括号围成语句块，缩进只用于阅读，不决定程序含义。局部变量的可见范围由所在块决定，内层块可以声明自己的同名变量。

```lency
int main() {
    var count = 1
    {
        var inner = 2
        print(inner)
    }
    return count - 1
}
```

结构体和枚举的定义同样使用花括号，但其中的成员声明不是普通语句块。

内层同名声明具有自己的绑定，离开块后恢复外层绑定；对外层变量的普通赋值仍保留其修改结果。

## 分号与换行

普通变量声明、赋值、调用和返回在清晰分行时可以省略末尾分号。同一行写多条语句时使用分号分隔。

```lency
int main() {
    var left = 1
    var right = 2; right = right + 1;
    return left + right - 4
}
```

换行不是缩进语法，也不保证在任何位置都结束表达式。不要把无值返回与下一条表达式仅靠换行分隔；用明确的块或分号避免歧义。

母体计数循环的外层括号和完整三段之间的分号独立可选；空段以分隔符标识位置。外部函数声明以分号结束。相关写法见[控制流](./control-flow.md)和[函数](./functions.md)。

## 注释与名称

单行注释从双斜线开始，到行尾结束。

```lency
int main() {
    // 计算结果
    var answer = 42
    return answer - 42
}
```

当前实现不支持块注释。类型名使用大驼峰形式，函数与变量使用小写下划线形式；具体命名约定见设计原则。名称大小写有区别，类型名和函数名没有仅凭拼写获得的错误处理特权。
