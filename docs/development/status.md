# 自举状态

## 当前阶段

项目处于混合自举阶段。Lency 自举编译器负责读取源码、语法与语义检查、发射项目 LIR；Rust 母体负责将 LIR 转为 LLVM 并完成构建和链接，runtime 仍由 Rust 实现提供。

阶段检查覆盖编译器 LIR、样例 LIR 和运行结果的收敛。LIR 收敛表示当前输入和工具链下输出一致，不等于完整功能等价，也不等于已经具备独立后端。

当前开发主线是自举编译器。Rust 母体承担已确认语法要求的对齐和参考行为缺陷修复，普通程序仍以母体作为默认编译入口；母体修改不作为继续扩展未定稿语言能力的理由。

Rust 母体以[固化基线](./stage0.md)定义的基础子集作为固定 stage0。基础契约由普通与优化构建的实际运行验收，不以自举收敛替代普通程序正确性。Rust 检查包含该验收入口，后续母体修改须保留这些契约。

## 可验证的范围

现有回归覆盖编译器自身使用的基础表达式、函数、控制流、字符串、Vec、模块签名，以及非泛型结构体、方法、枚举匹配的运行子集。语法可解析、语义可检查和端到端可运行是三个不同层级。

语法写法和两套前端的差异见[基础语法](../basics/syntax.md)。函数、返回、条件与集合的具体规则分别在[函数](../basics/functions.md)、[控制流](../basics/control-flow.md)和[Vec](../stdlib/vec.md)中说明。

自举三段式计数循环支持可选外层括号、两个独立可选的分号，以及显式类型声明、推导声明或赋值初始化。解析回归覆盖这些组合；运行回归核对循环次数、初始化作用域、更新执行、嵌套循环中的跳出和继续。编译器自身的循环重写也使用带括号且省略分号的形式。该支持范围要求三段完整，不代表母体已有的空段或遍历形式已进入自举子集。

自举 LIR 为局部声明和匹配绑定分配唯一名称，在离开块、分支、循环体及匹配分支时恢复可见绑定与类型元数据。对外层变量的赋值仍修改外层绑定，内层同名声明不覆盖其存储；循环跳转目标按嵌套层级入栈和出栈。

自举集合类型支持小写拼写，覆盖局部声明、函数参数与返回值、结构体字段、方法签名和嵌套集合。旧大写拼写映射到相同内部类型，混合拼写不绕过元素检查。解析器的入口、声明和语句模块使用小写集合类型；其他自举源码仍有兼容拼写。运行回归覆盖空集合追加、读取与写入、弹出、嵌套集合、方法返回和共享引用。

母体和自举逻辑运算均从左到右短路求值。自举 LIR 使用条件分支决定是否执行右操作数，运行回归覆盖操作数执行顺序与次数、嵌套表达式、函数参数和返回、循环条件、匹配守卫，以及跳过越界和除零表达式。运行时跳过的操作数仍接受名称和布尔类型检查。

母体的成员赋值回归覆盖接收者单次求值、非空检查后的可空结构体读写及结构体空值合并；非法赋值目标在语义检查阶段拒绝。可空标量回归覆盖零和假、赋值、参数和返回值、字段及安全导航、按值比较、可空元素集合和惰性空值合并；不代表所有容器与泛型组合已经完整验证。

## 当前阻塞

- 自举编译器尚无独立的 LLVM 或本机代码后端，阶段构建仍依赖 Rust 母体。
- 泛型实例化、完整方法与 trait 体系、完整标准库尚未形成稳定的自举运行子集。
- 两套前端仍有语法接受范围差异，不能直接互换所有测试输入。
- 母体接受 C 风格固定数组声明和模块前缀组合导入；自举前端尚需逐项核对和对齐这些完整形式。旧类型拼写与数组声明保留兼容入口供现有源码使用，不能当成新的公开语法方向。
- 母体 AST 路径登记函数、方法与原始文件行列，普通及优化构建覆盖跨文件递归、方法和运行时失败，间接调用另有源级回归。LIR 路径尚未携带同等源码映射，不能将母体 AST 路径的验收结果当作自举诊断能力。
- 当前内存策略为手动管理。母体 AST 路径提供浅层释放入口，结构体、枚举、可空值单元、动态字符串和运行时集合登记对应的释放方式；不执行 GC 或引用计数。调用者负责独立子对象及共享别名的有效期，泄漏和释放后使用不具备完整静态检查。LIR 路径尚未提供与母体相同的统一释放语法契约。
- 母体拒绝未支持的复杂调用目标及将函数名、类型名直接当普通结果值使用，不再以错误占位类型将这些输入判为成功。该边界不表示已完成任意表达式调用或具名函数值获取能力。
- HashMap 整数句柄属于兼容 ABI，不代表完整强类型容器抽象。标准字符串与 I/O 包装返回归属统一，重复调用验收核对手动分配余额，见[手动内存管理](../basics/memory.md)。
- runtime 字符串比较遇到可识别的非法标量句柄会报告 panic，不再伪装成字符串不相等；这不是合法类型转换，也不是对任意外部裸指针有效性的保证。

后续能力以编译器自身的数据结构、控制流和独立构建需要为准。实现差异属于待处理边界，不作为修改语言设计的依据。

## 验证入口

```powershell
cargo run -p xtask -- check-lency
cargo run -p xtask -- bootstrap-check
```

具体命令和环境配置见[工具与脚本](../tools/scripts.md)，阶段职责见[自举路线](./bootstrap.md)。运行回归位于 tests/example/runtime，语法与语义回归位于 tests/example/selfhost。本文只描述当前自举状态；逐次修改记录由 Git 历史承担。
