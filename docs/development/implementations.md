# 实现分层

语言设计、母体编译器行为和自举编译器能力是三个不同层次。设计原则确定预期语义；源码、测试和运行验证用于确认实际行为，不能仅凭实现差异改写设计。

## Rust 母体

母体位于 crates，承担普通程序编译、语义与后端参考、自举初始编译器和当前 LIR 后端的职责。承担已确认语法要求的对齐与参考行为修复，不以扩展未定稿语言能力为开发主线。

参考实现也可能存在缺陷。某个词法标记、解析分支或单元测试存在，不能单独证明对应特性已经完整编译和运行。

## Lency 自举编译器

自举实现位于 lencyc，是当前开发主线。它执行源码读取、词法与语法分析、语义检查以及 AST 或 LIR 发射。

阶段构建仍借用 Rust 母体将 LIR 转为 LLVM、生成目标文件并链接 runtime。当前属于混合自举，尚无独立本机后端。

## 能力用语

| 用语 | 含义 |
|---|---|
| 可解析 | 可以构造语法树，不保证类型合法或可生成代码 |
| 可检查 | 语义检查能够处理该输入，不保证后端可运行 |
| 可生成 LIR | 自举后端可以发射对应中间表示 |
| 端到端可运行 | 存在从源码经过自举 LIR、过渡后端和 runtime 到执行结果的回归 |
| 独立自举 | 不借用 Rust 母体后端即可构建下一阶段；当前尚未达到 |

LIR 发射对无法处理的节点和未知 ABI 类型报告错误，不以占位指令代表成功。即便如此，发射成功和阶段收敛仍不能取代程序语义与运行验证。
