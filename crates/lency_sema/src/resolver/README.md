# Resolver 模块

本目录解析标识符、声明、模块导入与作用域，并为后续类型阶段建立符号关系。

| 路径 | 职责 |
|---|---|
| `mod.rs` | resolver 状态和程序入口 |
| `builtins.rs` | 普通全局内建符号注册 |
| `imports.rs` | 模块查找与导入 |
| `decl.rs`、`decl_impl/` | 声明和 impl 解析 |
| `stmt.rs` | 语句作用域和控制流中的名称解析 |
| `expr.rs` | 表达式引用解析 |
| `types.rs` | 类型名称解析 |

内建函数必须像普通全局函数一样参与解析，且当前不能被用户同名声明覆盖。不得根据用户类型或枚举项名称赋予特殊语义。
