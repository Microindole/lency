# Type Check 模块

本目录验证已经解析的 AST 是否满足强静态类型约束。

| 路径 | 职责 |
|---|---|
| `mod.rs` | checker 状态和公共检查入口 |
| `decl.rs` | 函数、类型和实现声明检查 |
| `expr.rs` | 表达式、调用与 enum 构造检查 |
| `stmt/` | 语句和控制流检查 |

普通调用、嵌套调用、函数值调用和 enum 构造必须经过同一套参数数量及类型验证。发现不一致时应返回明确诊断，不得以 `unknown` 静默继续到 codegen。

赋值除检查类型兼容性外，还需验证目标是否表示可写存储。字面量、运算结果、函数调用结果、安全导航结果、枚举项与数组长度属性不能作为赋值目标；结构体字段使用声明的字段类型检查。
