# Parser 模块

本目录把 lexer token 流解析为 AST，并负责语法错误恢复。

| 路径 | 职责 |
|---|---|
| `mod.rs` | parser 状态、公共入口和顶层流程 |
| `decl.rs` | 函数、类型、impl、import 等声明 |
| `stmt.rs` | 局部变量和控制流语句 |
| `expr/` | 原子、后缀、一元和二元表达式 |
| `pattern.rs` | `match` 模式 |
| `helpers.rs` | token 消费和公共解析辅助 |
| boundaries.rs | 使用原始字节区间识别无值返回及分行调用的语句边界 |

语法接受不等于功能可用。新增语法必须同时确认 sema、lowering 和回归范围；`=>` 只用于 `match` 分支。

声明辅助解析器支持名称后的固定数组维度及声明位置的花括号初始化；多维数组从最左维度向内嵌套。计数循环将头部与循环体分别解析，括号和完整三段间的分号独立可选；空段用分隔符定位。组合导入将公共模块前缀展开为普通导入项，供现有模块加载流程处理。公开动态集合类型名为小写，旧拼写仅作为源码迁移的兼容入口。公共解析入口保留词法字节区间，供源码诊断定位使用。
